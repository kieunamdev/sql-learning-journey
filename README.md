## 🎯 Mục tiêu

- Thành thạo truy vấn dữ liệu: `SELECT`, `JOIN`, `GROUP BY`, CTE, Window Functions
- Nắm vững thiết kế bảng và thao tác dữ liệu (DDL / DML)
- Hiểu cơ bản về index và tối ưu truy vấn
- Xây dựng nền tảng SQL cho các project Data Engineering

## 🛠️ Công nghệ

- **PostgreSQL**: hệ quản trị cơ sở dữ liệu chính
- **DBeaver / pgAdmin**: công cụ chạy và quản lý query
- **Git & GitHub**: quản lý phiên bản
