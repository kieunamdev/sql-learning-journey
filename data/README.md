# 📁 Data

Thư mục này chứa dữ liệu dùng cho các bài tập SQL.

## 🎬 DVD Rental Database

- **Nguồn:** [PostgreSQL Tutorial - Sample Database](https://www.postgresqltutorial.com/postgresql-getting-started/postgresql-sample-database/)
- **Mô tả:** database mẫu về cho thuê DVD (khách hàng, phim, cửa hàng, thanh toán...)
- **Cách dùng:** tải file `dvdrental.zip` từ link trên, giải nén ra `dvdrental.tar`, rồi restore vào PostgreSQL (pgAdmin: chuột phải database → Restore).

> ⚠️ File dữ liệu không được đẩy lên repo, bạn cần tự tải về.
